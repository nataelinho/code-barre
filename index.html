    Cartes enregistrées

      Rien n'est gardé sur ce téléphone tant que vous n'appuyez pas sur Enregistrer. Scannez une carte pour la reproduire dans le même format que l'original ; si le format est inconnu, essayez Code 128, puis EAN ou QR.

      Dernier chiffre manquant ? Tapez seulement les 12 premiers, il est calculé tout seul. Pour passer devant la scannette : luminosité au maximum, et une scannette à caméra (les lasers ne lisent pas les écrans).
